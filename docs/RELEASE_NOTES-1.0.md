# Mio Music 1.0.0

首个可用的 Windows 便携版本，面向本地音乐收藏的逐首整理流程。

## 下载

下载 `MioMusic-windows-x64.zip`，完整解压后运行 `MioMusic/MioMusic.exe`。无需安装 Python、FFmpeg 或额外日语字典。Windows 10 / 11 x64。请保留整个目录。

## 已实现

- 原生 Qt 桌面窗口，暖白与森林绿界面、淡入动画、拖放与文件夹导入。
- 原采样率多窗口 STFT 频谱、带宽和峰值估计、启发式转码判断、JSON 报告。
- LRCLIB 歌词候选查询与版本选择、LRC 编辑和导出。
- 离线日语 Hepburn 罗马音，原文与转写分别保存，保留时间戳。
- MusicBrainz / Cover Art Archive 封面匹配、发行版选择、预览与本地图片导入。
- FLAC、MP3、M4A 歌词和封面嵌入；SHA-256 备份、原子替换、撤销与持久记录。
- 试听、会话内编辑草稿、多种异常路径保护、完整中文文档。

## 验证与边界

15 项自动测试通过，覆盖 FLAC、MP3、ALAC M4A、AAC M4A 写入前后音频样本一致、备份恢复、分析规则、罗马音与 GUI 线程。实际联网确认歌词搜索、专辑候选和封面下载可用。

频谱判读不能认证“真无损”；目前最多三段各 12 秒抽样。联网服务不保证所有歌曲有内容；同名版本需要用户核对。WAV / OGG / OPUS / AIFF 暂只分析与导出歌词。自动罗马音需人工校正特殊读音。

这是便携版，尚未代码签名；未提供自动更新、安装向导和自动批量写入。源码以 GPL v3 公开，第三方许可随包附带。

音频不会上传。联网只发送曲名、歌手、专辑等查询信息。备份保存在音乐目录 `.mio/backups`，请注意磁盘空间。
