# Mio Music 1.2.0 · Spotify 接入与写入工作台

## Spotify 歌词

接入 akashrchandran/spotify-lyrics-api。通过“Spotify 链接…”连接自己的服务，支持歌曲链接、URI 与 Track ID，获取后可预览、修改、生成罗马音并选择嵌入。随包提供固定版本的服务源码、加固配置和 Windows Docker 启动脚本。需要用户自己的服务端登录会话；没有内置共享账号，真实 Spotify 账号链路尚未验证。

## 写入与记录重做

- 歌词明确选择：保留文件原歌词、当前编辑区、原文＋罗马音预览、已获取/导入的具体版本。
- 封面明确选择：保留、仅缺失补全、主动替换；可以在多个已准备图片中选择，显示实际保存预览。
- 罗马音自定义标签独立更新，未选择时保留原标签；也可把原文＋罗马音直接作为标准歌词嵌入。
- 保存摘要和无效计划拦截；无更改或所选内容为空时不会保存。
- 备份后更新原件 / 另存整理副本，新副本不覆盖已有文件。
- 保存记录表与运行诊断分开；可选记录撤销，记录持久化并验证当前文件哈希。

## Windows 文件占用修复

选择歌曲不再立即加载试听；点击试听时才打开。保存与撤销前同步销毁旧播放器，释放解码器文件句柄。针对短暂文件锁有限重试，每次重试检查文件未被外部修改；仍被占用时保留原件并给出明确处理提示。真实 Windows 文件锁测试证明覆盖失败时原件哈希不变，并仍可另存副本。

## 验证

59 项自动测试通过，包含三种容器的封面替换/其他图片保留、独立罗马音、自选写入计划、副本与撤销、Windows 文件锁、试听释放，以及 Spotify 协议本地 HTTP 测试。Spotify 真实账号访问不包含在上述成功声明中。使用前请阅读 docs/SPOTIFY.md。

下载 MioMusic-windows-x64.zip，完整解压后运行 MioMusic.exe。退出旧版后从新目录启动，确认右上角 v1.2.0。无需安装 Python；可选 Spotify 后端需要 Docker Desktop 和自己的 SP_DC。
