# Mio Music 1.1.0 · 在线歌词可靠性更新

修复旧版仅接入 LRCLIB、服务返回 HTTP 503 后整次歌词查询不可用的问题。

## 本次改动

- 新增网易云音乐与酷狗歌词来源，保留 LRCLIB，自动模式并行查询。
- 单源错误不影响其他候选，来源状态直接显示在页面中；候选按来源标注。
- 支持手动选源、带歌手查询为空时回退曲名查询、强制刷新。
- 选择候选后后台获取歌词；失败不弹出阻塞窗口，不清空编辑内容，可直接选其他版本。
- 支持网易云提供的译文与日语罗马音，按时间戳对齐；保留离线转写入口。
- 搜索/正文分开缓存，网络失败可回退三十天内缓存并标记。
- 网络请求设置短超时和响应大小上限；不对 503 反复等待同一来源。

## 验证

29 项自动测试通过，包含模拟 LRCLIB 503、全源超时、部分成功、正文获取失败、缓存回退和编辑保护。

2026-10-28 真实联网检查：《Lemon / 米津玄師》《晴天 / 周杰伦》《Hello / Adele》均从三个来源搜索并成功获取正文；正常网络下此次搜索约 1–2 秒，不代表所有网络与歌曲均可用。未将完整歌词或封面保存进仓库。

下载 `MioMusic-windows-x64.zip`，解压后运行整个目录里的 `MioMusic.exe`。无需安装 Python、API 密钥或额外词典。Windows 10 / 11 x64。请退出旧版本后再用新目录里的程序；现有音乐与 `.mio` 备份可继续使用。

歌曲与版本需要用户核对。歌词来源属于第三方服务，可能随接口、地区和网络状况变化。频谱、备份和标签写入行为保持原有设计。该版本仍未代码签名。
