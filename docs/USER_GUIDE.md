# 使用说明

## 准备文件

建议先用少量复制的音乐文件熟悉流程。点击“导入音乐”可多选，“导入文件夹”会递归扫描；也可直接拖入文件或文件夹。重复绝对路径去重，损坏或不支持的文件跳过并在记录中显示。列表“移出工作台”不会删除磁盘文件。

未写标签的文件会以文件名作为曲名；在歌词页修改搜索曲名和歌手，在封面页修改专辑。这些输入只参与查询，不负责重命名或基本标签编辑。

## 频谱怎么看

点击“分析频谱”。横向是各抽样窗口内的时间，虚线分开不同窗口；纵向是频率，亮度表示能量。最高展示至 24 kHz。窗口起始时间标在底部，不把抽样拼图误认为全曲连续谱。

“疑似有损转码”表示频谱带宽偏窄，需结合其他证据；“未见明显转码迹象”并非证明真无损。MP3 等当前有损编码会直接注明。JSON 导出包含结论、原采样率、窗口数、估计带宽与平均频谱。

## 匹配歌词

填写曲名、歌手，点击查找。默认“自动 · 多源”会同时查询网易云、酷狗和 LRCLIB；可在来源下拉框只选一个平台。每个来源的成功、空结果、缓存或网络错误会显示在候选列表上方；一个来源 503 不影响其他来源。下拉框列出得分、歌手、曲名、专辑和时长。相似分数只辅助排序，不保证版本正确。选择后会后台获取该候选的正文，失败时保留当前编辑内容，可继续选其他来源。“带上来源提供的译文”在下次选择候选时生效；有在线罗马音时自动填入右侧，可人工修改或重新离线生成。选择成功后可修改左侧原文；同步 LRC 的时间戳会保留。标记纯音乐的候选不会清空已有歌词。

“生成日语罗马音”在右侧生成原文与罗马音交替的预览，可继续人工编辑。改动左侧原文会清空右侧过期转写，需重新生成。日语特殊读音、助词、人名需要校正；没有假名的纯汉字文本不自动判为日语。

“导入 LRC”读取 UTF-8 / UTF-8 BOM 编码 `.lrc` 或 `.txt`；其他编码请先另存为 UTF-8。“导出当前歌词”优先导出右侧原文＋罗马音，右侧为空则导出左侧原文。用不同文件名可以保留原 LRC。

勾选“重新联网”可跳过新鲜缓存。若网络失败且存在三十天内的旧缓存，会标注“缓存回退”。缓存目录为 `%LOCALAPPDATA%/MioMusic/cache/lyrics-v2`，删除该目录可清理歌词缓存。搜索无结果时，可去掉标题里的版本修饰或歌手别名；程序也会在带歌手查询为空时尝试只查曲名。

## 补封面

先在歌词页填写歌手，在封面页填写专辑，再查发行版。根据日期、地区和名称选择正确版本，点击预览。404 表示此发行版没有正面图片，换其他候选。已有封面默认保留，可在写入页显式选择替换。

本地封面支持 JPEG、PNG、WebP，最大 12 MB。写入时标准化为 JPEG，最大 1600×1600 范围内保持长宽比。不会拉伸成正方形。

## 保存内容与版本选择

“写入与记录”分为歌词和封面两个预览卡片。页面会缩小顶部歌曲卡片，把空间留给保存操作；小窗口可滚动。

歌词下拉框可选：保留文件里的歌词、当前编辑区、当前罗马音预览，以及本次会话已从各来源获取/本地导入的具体版本。每次获取会保留独立快照，可以比较后选择；之后继续编辑不会悄悄改变已选择的快照。想保存新编辑时，请选择“当前编辑区”。选择“当前罗马音预览”会把原文＋罗马音作为标准歌词写入，便于普通播放器显示。

“额外更新罗马音自定义标签”与标准歌词独立。未勾选则保留旧标签；勾选时使用当前右侧罗马音内容。所选内容为空时不允许保存。

封面先选择保留、仅缺失补全或替换，再在已经获取的图片中选择具体一张。预览显示实际将保存的封面，已有图片不会因为下载了新图片就自动被替换。替换保留 FLAC / MP3 的非正面图片。

下方摘要列出实际变化；没有变化时保存按钮不可用。“备份后更新原文件”保留完整备份后更新；“另存整理副本”会要求新文件名，不覆盖已有目标，适合文件被其他播放器占用或原件只读时使用。

保存前会释放 Mio 试听解码器。如果仍提示占用或权限问题，请关闭其他占用程序，检查只读属性/目录权限，或另存副本；程序不会强行结束其他程序。

## 保存记录与撤销

“文件保存记录”只显示当前歌曲相关的成功写入与另存操作，查询报错放在“运行诊断”，不会混在一起。切换歌曲会自动读取其目录 `.mio/history.jsonl`，可点击刷新。

选中记录再点击“撤销所选记录”。当前文件哈希必须等于该记录保存后的哈希，备份也必须匹配，才能恢复原件；若存在之后的操作或外部修改，会拒绝覆盖。通常应从最近可撤销的记录逐步向前恢复。已撤销记录不再作为可撤销记录显示。

另存操作的撤销是删除那次创建且未经修改的整理副本，原文件不变。“备份目录”跟随所选记录，可查看完整备份。副本保存在其他目录时，其持久记录位于目标目录 `.mio`；重新打开应用后可导入该副本查看记录。

仍可参照日志手动恢复：先保留当前文件副本，再把对应 `.bak` 复制回原目录并恢复原文件名。切换歌曲保留本次会话的编辑和写入选择，退出后不持久保存草稿；需要保留时导出歌词或保存文件。

## Spotify

点击歌词页的“Spotify 获取…”，首次配置自己的 SP_DC；默认内置直连，无需 Docker。之后可在曲名搜索框粘贴 Spotify 歌曲链接，点击“查找歌词”直接获取；结果加入版本选择列表。会话默认存入 Windows 凭据管理器，也可仅在本次使用，支持更新与清除。步骤见 [SPOTIFY.md](SPOTIFY.md)。Mio 不读取浏览器 Cookie；真实账号取词尚未验证。

## 常见问题

**为何 FLAC 还会提示疑似转码？** FLAC 能无损存储当前信号，但这个信号本身可能早已被 MP3 压缩过。反过来，高频截止也可能是母带本来就有的特征。

**为何找不到歌词/封面？** 标签不准确、服务缺失、版本不同、网络限制均可能造成无结果。手动纠正搜索字段，换其他发行版，或导入本地内容。

**为何播放器不显示罗马音？** 自定义标签兼容性有限。可导出双行 LRC 配合支持外挂歌词的播放器；Mio 不把转写强行混入标准原文。

**为何不能写 WAV？** 1.0 暂时只验证并开放 FLAC、MP3、M4A 的嵌入，以保证写入可靠。WAV 仍能看频谱、查询与导出歌词。

**为何程序体积较大？** 随程序携带 Qt、音频解码器、科学计算库和日语字典，因此无需安装运行环境。
